# `@railgun-reloaded/event-formatter`

> Event Formatter for Railgun Events

## Example Usage
```ts
    import { formatGeneratedCommitmentBatchEvent} from '../src/events-v1'

    // Format events
    const inputs = {...}
    formatGeneratedCommitmentBatchEvent(inputs)
    
```

## Install
```sh
npm install @railgun-reloaded/event-formatter
```
